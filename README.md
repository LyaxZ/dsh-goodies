# dsh-goodies

> [English](README.en.md) | **中文**

给 DeepSeek Harness（DSH）Web GUI 用的一小组小功能：模型菜单里的思考强度滑块、运行状态旁的实时速度与本轮用量、每条回答的成绩单。三项各自独立开关，都只作用于界面，不改模型请求、不改会话内容，也不上传任何数据。

## 功能

- **思考强度滑块**：模型菜单的「推理等级」变成一条横向粗轨道加白色滑块，拖动或点按都能切换，当前档位名显示在上方，真实默认档会标出来；档位名全部用模型原生提供的，不额外造 Off。轨道里有一层随档位加量的流光粒子，档位越高越快，颜色从浅蓝走到深蓝。
- **实时 tok/s**：回答下方的运行状态行右侧显示「★ 速度 · 本轮合计」。速度只按真正产生 token 的时间计算，调用工具、等待结果的时间不计入；合计与本轮用量面板同口径，1000 以上按 K / M / B 缩写。
- **每条回答成绩单**：用量右边补上输入 · 输出 · 缓存，时间右边补上总用时与输出速度；缺哪一项就写「—」，不会整段消失。
- **设置卡片**：出现在 设置 → 插件 → DSH Goodies，三个功能各有开关，另有一个「减少动效」开关（关掉滑块与粒子动画，功能不受影响）。

## 安装

通过 DSH CLI 安装：

```
dsh plugin --profile web add dsh-goodies
```

也可以从 GitHub 安装：

```
dsh plugin --profile web add github:LyaxZ/dsh-goodies
```

装完重启 DSH，再刷新页面。

## 使用

安装后打开 **设置 → 插件 → DSH Goodies**，按需开关。

- 滑块在模型菜单的「推理等级」里生效，档位名沿用原生叫法，默认档按模型的真实默认标出。
- 实时速度与成绩单跟随对话自动出现，不需要额外操作。
- 「减少动效」只影响动画，不改变任何读数。

## 开发

```powershell
node build.mjs      # 生成 lib/
node test/run.mjs   # 离线检查（样式契约、纯函数、构建产物）
```

- `src/shared.cjs`：纯函数与样式，浏览器与离线测试共用。
- `src/client.js`：浏览器半，三个功能与设置卡片。
- `src/index.mjs`：宿主半，只注册设置 schema。
- `lib/`：构建产物，不要手改。
- `test/hud-probe.mjs`：注入假的运行状态行，验证实时 HUD 与星星闪烁（需要一个带 token 的页面地址）。
